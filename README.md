# 📚 Exercícios Desenvolvidos

## 1️⃣ Números Inteiros Entre Dois Valores
Programa que solicita dois números inteiros e imprime todos os números existentes entre eles.

### Conceitos utilizados:
- Estrutura `for`
- Função `range()`
- Entrada de dados
- Operadores relacionais

---

## 2️⃣ Crescimento de Colônias de Bactérias
Sistema que calcula em quantos dias uma colônia de bactérias A ultrapassará ou igualará uma colônia B, considerando diferentes taxas de crescimento.

### Regras:
- Bactéria A:
  - inicia com 4 elementos
  - crescimento de 3% ao dia

- Bactéria B:
  - inicia com 10 elementos
  - crescimento de 1,5% ao dia

### Conceitos utilizados:
- Estrutura `while`
- Crescimento percentual
- Acumuladores
- Simulação de crescimento

---

## 3️⃣ Validação de Notas
Programa que recebe 15 avaliações de usuários e verifica se cada nota informada está entre 0 e 5.

Caso a nota seja inválida:
- o sistema solicita uma nova entrada até receber um valor válido.

### Conceitos utilizados:
- Estruturas de repetição
- Validação de dados
- Condicionais
- Entrada de dados

---

## 4️⃣ Média de Temperaturas
Aplicação que lê temperaturas em Celsius e calcula a média dos valores informados.

### Regra:
- O programa encerra quando o valor `-273°C` é digitado.

### Conceitos utilizados:
- Laço `while`
- Condição de parada (sentinela)
- Acumuladores
- Média aritmética
